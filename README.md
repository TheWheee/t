a small [neocities](neocities.org ) website for myself so others can know a ltile more about me, made for [hack club terra ](https://terra.hackclub.com/)

originally,  some of the base code was made  by me when i was like 12-13, (so the fade-in and background colors etc), i decided to use the same code, completely revamping it with additions i didn't understand and could get to work when i was way younger, such as the snow particles, (thank you https://codepen.io/massiebn/pen/OJMbXz!)
and the compact ui with multiple sidebars with different information. 

The left sidebar contains links to some of my socials,  my signal, telegram, instagram(to be added :p) signal, github and my discord.   


 The `<main>` tag contains the (could you believe it) central part of the website, with a minor biography and info.  
 The right sidebar just hosts the music player, but i plan on adding more stuff later on. 
 The `<footer>` has the whiteredwhite Belarusian flag- Жыве Беларусь!
